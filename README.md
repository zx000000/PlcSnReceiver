# PLC FINS UDP SN 接收工具

欧姆龙 PLC FINS/UDP 上位机接收工具，.NET 10 + WPF，用于接收 PLC 推送的 SN 码/多组数据。

## 三个页面

| 页面 | 功能 |
|------|------|
| 状态监控 | 顶部「各通道状态一览」总览所有通道运行状态；每个通道一个页签，含该通道**独立启动/停止按钮**、连接状态、PLC 地址、会话/累计计数、实时日志、数据动态表格；顶部按钮可启动/停止所有通道、清空/导出当前通道列表 |
| 历史查询 | 顶部下拉选通道，按起止日期 + 可选字段关键词，查询该通道独立 SQLite 历史记录并导出 CSV |
| 参数配置 | 左侧通道列表（可增删、**可命名/改名**），右侧配置选中通道的 FINS UDP 通信、触发信号、可动态增删的采集数据项（支持字符串/整数/**浮点**类型）；下方全局存储设置（自动保存、列表/日志上限、历史保留天数），本地持久化，启动自动加载 |

## 核心特性
- **多通道同时采集**：支持同时配置多个 PLC 通道，每通道一套独立的 PLC 通信参数、触发与数据项，并有**独立的数据库文件**（`records.db`、`Channel2.db`…），配置与历史数据完全隔离，互不干扰。
- **通道命名与改名**：配置页可自定义/修改每个通道的名称（如「产线A」），用于监控页签标题与查询下拉；改名不影响该通道历史数据库文件。
- **独立启停与状态一览**：监控页每个通道页签可**单独启动/停止**，也保留顶部「启动/停止所有通道」批量控制；顶部「各通道状态一览」实时总览所有通道运行/停止状态，页签内同步显示采集状态、连接状态点、PLC 地址与会话/累计计数。
- **自实现 FINS UDP 客户端**（无需第三方库），协议与桌面的 `sn-collector-4` 项目及配套 `SnSimulator` 模拟器完全一致（10 字节 FINS 头、无标识/长度字段、DM 字区 `0x82` / 位区 `0x02`、响应解析兼容 HSL Server 偏移），因此可直接对接该模拟器与欧姆龙直连 PLC。
- **多数据项可配置扩展**：在配置页「＋新增数据项」即可加 SN2、批次号、数量等，监控/查询表格列自动跟随，无需改代码、不改数据库表结构。
- **多种数据类型**：字符串（ASCII/Unicode）、无符号/有符号 16/32 位整数，以及 **IEEE754 浮点 Float32（2 寄存器）/ Float64（4 寄存器）**，大端序解析，适合温度、电压、重量等模拟量。
- **触发机制**：轮询各通道触发寄存器，检测上升沿后一次性读取全部数据项并打包为一条记录，可选读取后回写复位触发位。
- **防卡顿数量上限**：监控列表、日志框保留行数可在配置页设置（默认列表 1000 条 / 日志 500 行），超出自动移除最旧（仅影响 UI 显示，已入库数据不受影响）。
- **历史数据长期不卡顿**：SQLite 启用 **WAL 模式 + 时间索引**，并按「历史保留天数」（默认 90 天）自动清理超期数据并 **VACUUM 压缩**，防止数据库无限变大变慢。
- **兼容旧版配置**：旧版单通道 `config.json` 启动时自动迁移为多通道结构，并沿用原 `records.db` 保留历史数据。
- 配置存 `config.json`，各通道历史分别存独立 SQLite 库文件，均位于程序运行目录，启动自动加载。

## 运行方式
- **VS2026**：打开 `PlcSnReceiver.csproj`（.NET 10 SDK），F5 运行。
- **直接运行**：`bin\Debug\net10.0-windows\PlcSnReceiver.exe`（已编译好）。

## 首次使用（对接真实 PLC）
1. 打开「参数配置」页，左侧「＋新增通道」可加多个 PLC 通道；选中通道后在顶部「通道名称」输入框自定义名称（如「产线A」）。
2. 右侧填该通道的 PLC IP、FINS 端口(9600)、本机监听端口、本地/PLC 节点号。
3. 设该通道触发寄存器（如 D100），PLC 把该位写 1 时触发读取。
4. 「＋新增数据项」按需增删：字段名称 = 表格列名，寄存器地址支持 `D110`/`W20`/`H5` 等；数据类型可选字符串/整数/**浮点(Float32 占 2 寄存器、Float64 占 4 寄存器)**，字符串再选编码。
5. 点「测试选中通道连接」验证通信 →「保存配置」。
6. 回「状态监控」页：可点击通道页签内的启动/停止单独控制，或「启动所有通道」同时采集多个 PLC；顶部「各通道状态一览」实时显示各通道运行状态。

## 项目结构
```
PlcSnReceiver/
├─ PlcSnReceiver.csproj        （.NET 10 WPF，依赖 Newtonsoft.Json + Microsoft.Data.Sqlite）
├─ App.xaml / MainWindow.xaml  （TabControl，三页）
├─ Models/
│   ├─ Enums.cs                数据类型/编码/内存区
│   ├─ AppConfig.cs            配置模型（Channels 多通道列表 / 全局存储设置）
│   ├─ PlcRecord.cs            接收记录（字段值用字典，支持动态扩展）
│   └─ RegisterAddress.cs      寄存器地址解析（D110 等 → 区码+字地址）
├─ Services/
│   ├─ FinsUdpClient.cs        自实现 FINS UDP 客户端（最小协议，与桌面 sn-collector 项目/模拟器一致，兼容 HSL Server；支持字符串/整数/浮点解析）
│   ├─ FinsUdpService.cs       单通道轮询/触发/读取编排，事件上报（多通道 = MainWindow 每通道一个实例）
│   ├─ ConfigService.cs        config.json 读写（含旧版单通道配置自动迁移）
│   ├─ SqliteDbService.cs      历史记录读写（每通道独立库，WAL/索引/超期清理+VACUUM）
│   └─ CsvExporter.cs          CSV 导出（UTF-8 BOM，Excel 兼容中文）
└─ UserControls/
    ├─ MonitorPage.xaml(.cs)   状态监控页（各通道状态一览 + 每通道页签独立启停 + 动态列）
    ├─ QueryPage.xaml(.cs)     历史查询页（通道下拉，动态列）
    └─ ConfigPage.xaml(.cs)    参数配置页（通道列表增删/改名 + 数据项增删/类型选择）
```

## 说明
- 编译状态：`dotnet build` 0 警告 0 错误，冒烟运行正常，`config.json` 自动生成。
- 默认样例配置为演示用，`PLC IP`、节点号、寄存器地址需按你的实际 PLC 程序修改。
